# Використання проєкту

## Запуск агента у VS Code

1. Відкрийте кореневу папку репозиторію у VS Code.
2. Відкрийте Copilot Chat.
3. У меню вибору агента виберіть `build-engineer`.
4. Введіть `/init` і надішліть повідомлення, щоб виконати ініціалізацію проєкту та перевірку.

Щоб окремо перевірити поточний стан проєкту, виберіть `build-engineer` у Copilot Chat, введіть `/check` і надішліть повідомлення.

## Локальна збірка та перевірка

Потрібні JDK 25 і Maven.

На Linux або macOS з кореневої папки репозиторію виконайте:

```bash
./ci.sh
```

На Windows у PowerShell виконайте:

```powershell
.\ci.bat
```

У командному рядку Windows виконайте:

```bat
ci.bat
```

Скрипт запускає Maven-перевірку (`mvn -B -ntp verify`) і копіює зібраний JAR у `dist/hello.jar`.

## Запуск застосунку

Після успішної збірки з кореневої папки репозиторію виконайте:

```bash
java -jar dist/hello.jar
```

Очікуваний вивід:

```text
Hello, World!
```

## Запуск тестів

З кореневої папки репозиторію виконайте:

```bash
mvn -B -ntp test
```
